# Tri sans emoji

Trie l'explorateur de fichiers par ordre alphabétique en ignorant les emojis en début de nom : « 🫀 Cardiologie » est rangé à C.

Le tri par date d'Obsidian reste inchangé.

## Installation avec BRAT

1. Installer BRAT dans le vault
2. Dans BRAT, choisir **Ajouter une extension bêta** et coller l'adresse de ce dépôt
3. Activer **Tri sans emoji** dans les extensions communautaires

L'infobulle du nom du coffre (en bas à gauche) affiche aussi le nombre de notes : « 748 fichiers (492 notes), 30 dossiers ».
